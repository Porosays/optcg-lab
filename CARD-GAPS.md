# Cards that need hand-written effects

The card importer couldn't turn these cards' text into engine effects, so they currently play with **no effect**. Hand-written so far (Nov 9): EB05-013, EB05-017, EB05-028, EB05-034, EB05-044, EB05-049, OP18-001, OP18-012, OP18-041, OP18-047, OP18-061, OP18-092. Decks using them are underrated until they're written. Leaders matter most.
